How it works

Three steps. No installation, no account, no technical skill required.

  1. 1

    Plug in the USB

    Insert it into the laptop you're checking.
  2. 2

    Double-click "Start Laptop Guardian"

    Open the USB drive and run the program. Click "Yes" if Windows asks for permission — this is needed to read hardware information.
  3. 3

    Get your report

    A full health report opens automatically once the check finishes — about a minute later.

Questions people ask

The things that surprise people the first time.

Why does Windows ask for permission?

Reading hardware information needs administrator permission. Click "Yes" when Windows asks so the check can see the battery, disk and BIOS details.

How long does it take?

About 1-2 minutes. The report opens by itself when the check finishes.

Can I copy it to another USB stick?

Each Laptop Guardian is locked to its own USB stick and won't start from a different drive.

Does it check for viruses?

No. Laptop Guardian checks hardware health only. Malware Guardian is the companion tool for security checks.
